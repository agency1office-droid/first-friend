# 퍼스트 프렌드 서비스 완성 결과 리포트

작성일: 2026-08-10

## 결과 요약

브레인스토밍, 제품 명세, 개발 계획, 농림축산검역본부 공공데이터 구조와 SEED Design의 현재 구성요소를 기준으로 퍼스트 프렌드를 모바일 앱형 서비스로 확장했다. 공개 탐색은 개와 고양이로 제한하고, 입양 준비·신청·상담·전자 동의·인계·양측 확인까지 하나의 기록 흐름으로 연결했다.

## 구현한 서비스 영역

- 집 근처 우선 동물 탐색, 개·고양이 전용 필터, 품종·털색·나이·성별·지역 조건 검색
- 직접 그리기, 사진 올리기, 조건으로 찾기의 독립 페이지와 시각 특징 태그 변환
- 검색 조건 저장 및 신규 동물 알림 기반, 추천 이유 표시
- 다중 사진·영상 저장, 중복 사진 제거, 사진 수 배지, 원본 이미지 보기
- 입양 준비도 진단, 필수 교육·시험, 잘 맞는 점·준비할 점·상담 필요 항목
- 초기비용·월비용·접종·중성화·병원비·응급예비비 계산기와 필수 제품 목록
- 고양이·강아지 백과: 최대 크기, 필요 공간, 생활 장점과 불편·위험을 함께 안내
- 입양 신청서, 보호자 적합도 점수와 이유, 보호소 신청자 정렬·비교
- 내부 상담 메시지, 표준 입양 동의 전자 기록, 인계 예약·준비물·양측 완료 확인
- 가족 상의 방: 공유 링크, 익명 의견, 동의·질문·걱정 분류, 모바일 공유 기능
- 개인 임시보호자 교육·약관·동물 등록, 다중 미디어·건강·구조·생활 정보, 신청자 관리
- 보호소 인증, 프로필, 소식, 입양 동물, 봉사 공고·지원, 필요 물품·후원 의사 기록
- 실종·발견 사진/특징/지역 매칭, 비공개 메시지, 소유 확인 답변, 목격 시간선, QR 전단, 해결·종료
- 공개 위치를 시·군·구 또는 동네 수준으로 제한하고 연락처·급식 장소·정확한 구조 위치 차단
- 이야기 게시·수정·삭제·공유·공감, 신고 누적 자동 블라인드, 운영자 검토·복구·제재
- 운영자 콘솔: 인증·직접 등록·신청자 적합도·신고·숨김·계정 제재·감사 기록
- 마이페이지: 관심 동물, 신청, 교육, 알림, 가족 상의, 메시지, 글, 임보 등록, 도움 기록
- 지역 TNR 안내와 공적 도움 연결, 운영 후원·굿즈·보호소 물품·제휴·보험 연결 안내
- 사이트맵·robots·페이지별 메타데이터와 앱형 상단/하단 내비게이션

## SEED Design 반영

실제 사용자 흐름에 맞춰 ActionButton, Accordion, Avatar, Badge, BottomNavigation, BottomSheet, Callout, Checkbox, Chip, Dialog, Divider/ListDivider, List/ListItem, ProgressCircle, RadioGroup, SegmentedControl, Slider, Tabs, TextField, NotificationBadge 계열을 적용했다. 구성요소를 장식용으로 억지 배치하지 않고 입력·피드백·선택·내비게이션·상태 표현에 사용했다. 디자인 기준은 공식 구성요소 문서와 Apache-2.0 저장소다.

## 데이터와 운영 원칙

- 농림축산검역본부 구조동물·보호소·분실동물 REST 데이터를 서버에서 정규화하고 캐시한다.
- 공공데이터에 없는 다중 사진·영상·건강·성격·생활 정보는 인증 보호소와 임시보호자가 보완한다.
- 공고 갱신 시 최신 데이터를 다시 받아 상태를 반영하며, 직접 등록 데이터는 운영 검토 상태를 가진다.
- 동물 자체에 별점이나 인기 점수를 붙이지 않는다. 적합도는 입양자의 준비 환경과 해당 동물 조건 사이의 설명 가능한 비교다.
- 입양 후 공개 일기 작성을 강제하지 않는다. 전자 동의, 메시지, 인계 확인은 내부 운영 기록으로 남긴다.

## 외부 계약 때문에 교체 가능 경계로 둔 항목

아래 항목은 화면만 흉내 낸 것이 아니라 내부 의사·상태 기록까지 동작한다. 다만 실제 외부 처리는 계약 또는 비밀 키가 필요해 `lib/integrations.ts`에 `DUMMY` 주석이 있는 어댑터로 분리했다.

- PG 결제 승인과 환불: 현재 후원·굿즈·물품 지원 의사를 기록하며 실제 결제는 실행하지 않는다.
- 보험·제휴 스토어: 퍼스트 프렌드가 직접 판매하지 않고 제휴사 이동 전 의사 기록을 남긴다.
- 카카오·인스타그램 전용 SDK: Web Share API와 링크 복사는 실제 작동하며 전용 SDK는 교체 지점으로 남겼다.
- 정밀 지도·경로: 공개 화면은 의도적으로 대략 위치만 사용하며, 인계 당사자용 지도 공급자 연결 지점을 분리했다.
- 외부 문자·푸시·메일: 서비스 내부 알림은 작동하고 외부 발송 어댑터는 계약 후 연결한다.
- 동물 이미지 전용 대규모 AI 모델: 브라우저의 색상·형태 특징 추출과 선택 태그 매칭은 작동한다. 향후 검증된 모델을 같은 인터페이스에 연결할 수 있다.

## 검증 결과

- 프로덕션 빌드 성공
- ESLint 오류 0건
- 서버 렌더링·공개데이터·입양 흐름·다중 사진·검색·운영 경계 통합 테스트 12/12 통과
- 데이터베이스 마이그레이션 생성 및 배포 패키지 포함 확인
- 외부 키와 사용자 연락처가 클라이언트 코드에 포함되지 않도록 확인

## 운영 전에 필요한 현실 업무

코드로 대신할 수 없는 계약 업무는 서비스 오픈 정책에 맞춰 진행해야 한다. PG·보험·제휴사 계약, 개인정보 처리방침과 전자 동의 문구의 법률 검토, 보호소 인증 담당자 배정, 신고·이의신청 응답 기준, 공공 API 운영키 갱신 관리가 이에 해당한다. 이 항목들은 기능 축소 사유가 아니라 실제 거래·분쟁 대응을 위한 운영 준비 항목이다.
