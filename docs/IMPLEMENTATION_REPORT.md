# 퍼스트 프렌드 구현 결과 리포트

작성일: 2026-08-09

## 1. 완성한 서비스 범위

세 기획 문서의 배경 서사, 제품 명세, 개발 계획을 하나의 실제 사용자 여정으로 통합했다.

1. 발견: 전국 공공 보호동물 목록과 상세 건강카드, 즐겨찾기
2. 탐색: 직접 그리기, 6색 팔레트, 굵기, 되돌리기, 초기화, PNG 저장, 사진 업로드, 품종·털색·나이·성별·지역 조건 검색
3. 준비: 주거 허용, 동거인 동의, 부재 시간, 돌봄 시간, 안전 설비, 기존 동물, 장기 부재, 경험 점검
4. 비용: 월 고정비·초기 준비비·비상 진료비의 현실적 범위와 개인 예산 시뮬레이터
5. 교육·시험: 고양이/강아지별 필수 교육과 10문항 시험, 80점 통과, 문항 해설과 재도전
6. 신청: 준비 시험 통과 확인, 생활·일상·부재·응급 계획, 개인정보·직거래 금지·사실 고지 동의
7. 상담·완료: 신청 진행 단계, 기록형 안전 메시지, 표준 전자 약정, 방문/봉사자/전문 운송 예약, 이동 체크리스트, 양측 인계 확인
8. 임시보호: 별도 5문항 교육, 사진 업로드, 구조 사연·건강·생활·입양 조건 직접 등록과 검토 상태
9. 이야기: 입양 일기·동네 친구·오늘의 추억·보호 이야기, 자격별 작성, 사진, 응원, 신고, 댓글 없음
10. 실종·발견: 공공 분실동물 목록, 사진 제보, 발생 시각·지역, 소유 확인 질문, 지역 알림, QR 전단지 저장
11. 보호센터: 전국 공공 보호센터 운영시간·대상·전화 정보
12. 개인화: 관심 동물, 준비 결과, 신청, 글, 실종 신고, 직접 등록을 모은 나의 페이지

## 2. 공공 API 적용

- 농림축산검역본부 국가동물보호정보시스템 구조동물 조회
- 시도·시군구·품종 코드 조회 구조 학습 및 필터 데이터 모델 반영
- 동물보호센터 조회
- 분실동물 조회
- 10분 서버 캐시와 7초 요청 제한, 장애 시 안전한 기본 데이터 전환
- 공개 화면에서는 개인 연락처와 정확한 주소를 숨기고, 실제 신청 뒤에만 공식 보호센터 전화와 시·도 수준 주소를 제공
- API에 없는 성격·질환·접종 상태는 생성하거나 추정하지 않음

## 3. 디자인 시스템

공식 SEED Design 저장소의 패키지와 레지스트리를 프로젝트에 포함했다. Action Button, Tabs, Segmented Control, Radio Group, Checkbox, Slider, Accordion, Progress Circle, Callout, List, Badge, Avatar, Text Field 등 사용자 흐름에 맞는 구성요소를 광범위하게 적용했다. SEED 토큰을 기반으로 모바일 폭 520px 중심의 화면, 고정 하단 탐색, 터치 영역, 상태색, 간격과 타이포그래피를 통일했다.

## 4. 임의로 확정한 제품 결정

- 그림·사진 검색은 근거 없는 AI 판정 대신 공공데이터의 품종·털색·나이·성별·지역을 사용하는 설명 가능한 특징 매칭으로 구현했다. 건강·성격·입양 성공 가능성은 점수화하지 않는다.
- 준비도는 참고 점수, 종별 지식 시험은 80점 이상을 신청 조건으로 분리했다.
- 공공 API에는 입양 신청을 전송하는 기능이 없으므로, 퍼스트 프렌드가 신청 기록을 보관하고 사용자가 공식 보호센터로 후속 연락하도록 명확히 안내한다.
- 보호자 직접 등록은 교육을 통과한 로그인 사용자만 가능하고, 등록 즉시 공개하지 않고 `review` 상태로 둔다.
- 공개 글에서 전화번호·이메일·정확한 주소 패턴을 차단하며 댓글은 제공하지 않는다.
- 동일 게시물 신고 50건에서 자동 숨김 처리하고 운영자 검토·이의 제기를 전제로 기록한다.
- 전자 약정에는 임의 벌금이나 사적 처벌을 넣지 않고 평생 돌봄, 재판매 금지, 파양 전 상담, 학대 의심 신고를 포함했다.
- 후원·굿즈·보험은 기획상 후속 단계이므로 결제처럼 오인되는 가짜 기능을 열지 않고 운영 원칙만 표시했다.

## 5. 데이터·보안

- D1 테이블: 회원, 관심 동물, 준비 평가, 신청, 약정, 인계 예약, 상담 메시지, 직접 등록 동물, 이야기, 반응, 실종·발견, 신고
- R2 업로드: JPEG/PNG/WEBP만 허용, 최대 8MB, 무작위 경로, 인증 사용자만 업로드
- 쓰기 API는 모두 서버 인증과 제재 상태를 확인
- 사용자 입력 길이 제한, 공개 개인정보 패턴 차단, 본인 소유 신청 조회 제한
- 공공 API 인증키는 Sites 비밀 환경변수에만 저장하고 소스에 포함하지 않음

## 7. 실제 운영 전 외부 절차

서비스 코드는 운영 가능 상태지만 다음 업무는 코드만으로 대신할 수 없다.

- 보호센터·임시보호자와의 실제 제휴 및 신청 상태 승인 운영
- 전자 약정 문구의 관할 법률 검토
- 학대·긴급 구조 신고의 지자체·경찰 운영 협약
- 신고 검토·이의 제기 담당자와 응답 시간 기준
- 결제·후원·보험을 열 경우 별도 사업자·전자금융·보험 규제 검토

이 항목들은 가짜 자동화로 감추지 않았으며, 외부 승인이 필요한 운영 경계로 서비스 안내에 반영했다.
