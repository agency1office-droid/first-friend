# 퍼스트프렌드 디자인 시스템·레이아웃 점검 리포트

작성일: 2026-08-10

## 적용 원칙

- 전체 시각 언어, 토큰, 실제 UI 구현은 SEED Design을 기준으로 유지했다.
- 일시적인 성공·실패·완료 피드백은 SEED Snackbar로 통합했다. 스낵바는 한 번에 하나씩 큐로 표시하며 기본 4초, 오류는 5.5초 후 사라진다.
- 사용자의 판단이나 지속 확인이 필요한 정보는 Callout, Alert Dialog, 본문 카드에 남겨 스낵바와 역할을 섞지 않았다.
- Toss Board Row는 패키지나 토큰을 혼합하지 않고, 밀도 높은 Q&A 정보 행이라는 구조만 참고했다. 실제 구현은 SEED Accordion을 사용해 키보드·스크린리더 접근성을 유지했다.

## 구현 내용

### 전역 피드백

- 관심 동물 저장/해제
- 저장 검색 알림 생성·수정·삭제
- 가족 상의방 생성·공유·의견 제출
- 입양 신청 절차의 메시지, 동의, 인계 예약, 인계 확인
- 게시물 신고·공유
- 임보자·보호소·운영자 관리 액션
- 봉사 지원과 후원 관심 등록

위 액션의 임시 본문 메시지를 제거하고, positive/critical 상태를 구분한 SEED Snackbar로 일관되게 표시하도록 변경했다.

### 정보 행

- 동물 상세의 `만나기 전 확인`
- 입양 준비 페이지의 `첫날 전에 꼭 준비할 것`

두 영역을 짧은 제목, 식별 가능한 접두 표식, 펼쳐지는 상세 내용으로 재구성했다.

### 레이아웃과 정렬

- 상세·그림·사진·조건 찾기 페이지의 중복 뒤로가기를 제거했다.
- 뒤로가기, 더보기, 상단 아이콘의 최소 터치 높이를 44px로 맞췄다.
- 색상 선택 버튼을 36px로 키우고 업로드 입력의 키보드 포커스를 보강했다.
- 420px 이하에서 조건 폼, 그림 도구, 인라인 폼, 관리 카드, 운영 액션을 한 열 또는 유연한 행으로 재배치했다.
- 운영 목록과 관리 카드의 긴 텍스트가 액션 버튼을 밀어내지 않도록 최소 너비와 줄바꿈을 정리했다.
- 상세 정보 값, CTA, 스토리 액션, 하단 고정 액션의 줄바꿈과 간격을 보정했다.
- 521px 이상에서는 앱 셸의 경계를 명확히 해 데스크톱에서도 모바일 앱 형태가 깨지지 않게 했다.

## 점검 범위

다음 경로를 390×844 모바일 뷰포트에서 확인했다.

- `/`
- `/find`
- `/find/draw`
- `/find/photo`
- `/find/conditions`
- `/friends/427346202600751`
- `/prepare`
- `/readiness`
- `/encyclopedia`
- `/lost-found`
- `/shelters`
- `/stories`
- `/support`
- `/tnr`
- `/mypage`
- `/operations`

인증이 필요한 `/operations`는 비로그인 상태에서 로그인 화면으로 안전하게 이동하는 것까지 확인했다.
