# 동물 DB 관리

2026-09-07: 기존 직접 등록 심사와 별도로 동물·입양 → 공공 동물 DB를 추가했다.

- 공공 동물 DB: 실제 public_animals 전체(수집 중/종료 포함), 20건 페이지, 정확한 전체 건수, 동물번호·공고번호·이름·보호소·지역·품종 검색, 숨김 필터, 사진과 원본 정보, 공개 상세 링크.
- 사이트 숨김/복구: 공공 데이터의 active/process_state와 분리된 hidden 필드. 동기화 upsert가 hidden을 보내지 않아 기존 숨김 상태를 유지한다. 공개 검색 RPC·품종 집계·필터·보호소 목록·상세는 visible_public_animals 뷰를 통해 숨김을 제외한다.
- 직접 등록: 기존 승인/종료와 함께 이름·종류·지역·구조 이야기·입양 조건을 수정한다. 등록자·심사 상태를 임의로 바꾸지 않는다.
- 모든 변경은 관리자 확인, 사유, 행 잠금과 이전 값 검사, 원자적 감사 기록을 거친다. 일반 회원/보호소는 공공 DB 관리 불가.
- 공고번호(notice_no)는 원래 저장하지 않았다. 기존 행은 다음 수집부터 채워지고, 그전에는 동물번호/이름/보호소로 찾는다.
- 공개 캐시(서버 목록·상세 60초, HTTP 캐시)가 남아 이미 열린 화면에는 숨김 반영이 지연될 수 있다. DB 목록은 즉시 반영된다. 원본 사진 URL 자체를 삭제하거나 비공개화하는 기능은 아니다.
- 공공 원본 사실의 덮어쓰기, 영구 삭제, 사진 업로드 교체는 이번 범위에 없다. 데이터는 수집 원본을 보존하고 노출 상태를 관리한다.
- SEED 기존 입력·선택·배지·확인창 사용. TDS 미참고.

검증: npm run lint, npm test, tests/animal-management.sql(격리 DB에서 실행 후 rollback), Chrome fixture UI. 운영 DB의 회원/동물은 검증 목적으로 변경하지 않는다.
