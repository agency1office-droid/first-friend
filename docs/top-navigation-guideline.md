# 퍼스트 프렌드 상단 내비게이션 규칙

상단 UI는 페이지 역할에 따라 아래 네 패턴만 사용한다. 기본 높이는 56px, 좌우 여백은 16px, 아이콘 터치 영역은 44px이다. 제목은 한 줄 말줄임 처리한다.

## 1. 홈형

- 적용: `/`
- 왼쪽: 현재 동네 설정
- 오른쪽: 읽지 않은 개수가 표시되는 알림, 전체 메뉴
- 홈에서만 지역이 상단의 주 정보가 된다.

## 2. 주요 탭형

- 적용: 홈 외 하단 내비게이션의 최상위 화면과 주요 허브
- 왼쪽: 페이지명
- 오른쪽: 알림, 전체 메뉴
- 뒤로가기를 표시하지 않는다.

## 3. 하위 탐색형

- 적용: 목록에서 진입한 검색, 지도, 도움말 및 관리 화면
- 왼쪽: 실제 이전 방문 화면으로 돌아가는 아이콘
- 가운데: 짧은 페이지명
- 오른쪽: 해당 화면에 실제로 연결된 행동만 배치한다.
- 전용 행동이 없으면 빈 공간을 유지해 제목을 화면 중앙에 둔다.

## 4. 상세·작업형

- 적용: 동물·게시물 상세, 입양 신청, 글 작성, 설정
- 왼쪽: 뒤로가기
- 가운데: 상세 또는 현재 작업명
- 오른쪽: 공유, 저장, 완료 등 현재 콘텐츠와 직접 관련된 행동만 허용한다.
- 전용 행동이 없으면 장식용 버튼을 만들지 않는다.
- 상세·폼 화면에서는 하단 주요 내비게이션을 숨긴다.

## 공통 동작

- 뒤로가기는 앱 내부 방문 기록을 우선하고, 기록이 없을 때만 정의된 대체 경로로 이동한다.
- 상단은 스크롤 중 고정되며 콘텐츠를 가리거나 화면 너비를 바꾸지 않아야 한다.
- 알림이 0개면 숫자 배지를 숨기고, 1~99는 실제 숫자, 100 이상은 `99+`로 표시한다.
- PC에서도 모바일 앱 프레임 내부에서 같은 정렬과 간격을 유지한다.
